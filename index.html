03｜只知道店名，還不知道地址

小明去「地址查詢中心」問：Yummy Burger 在哪裡？ 網路世界裡，這個查詢系統叫做 DNS — Domain Name System｜網域名稱系統。
幫忙把網域名稱查成 IP 位址的是？

04｜查到真正門牌

DNS 告訴小明真正的位置。這個像「門牌地址」的東西，就是 IP Address｜IP 位址。
網路世界裡像「門牌地址」的是？

05｜從家裡進入大城市

小明不能直接從家裡瞬間進入整座城市，他要先經過「道路入口管理單位」。 網路世界裡就是 ISP — Internet Service Provider｜網際網路服務供應商。
幫你把家裡、學校或手機接上 Internet 的是？

06｜一路經過很多路口

每到一個路口，都有人判斷「下一站該往哪裡走」。 網路世界裡，這個角色就是 Router｜路由器。
決定資料下一站往哪裡傳的是？

07｜資料不是一大箱一起搬

大量資料會被拆成很多小箱子來運送。這些小箱子叫做 Packet｜封包。
被拆成一小份一小份傳送的資料叫做？

08｜終於找到真正放資料的地方

漢堡店就像真正保存網站資料的地方。網路世界裡叫做 Server｜伺服器。 小明這一端正在「要資料」，所以是 Client｜用戶端。

小明說「我要看菜單」，店家回答「好，資料給你」。 Client 和 Server 需要遵守共同的溝通規則，這就是 HTTP — Hypertext Transfer Protocol｜超文字傳輸協定。 如果使用安全、加密的方式，就是 HTTPS — Hypertext Transfer Protocol Secure。
